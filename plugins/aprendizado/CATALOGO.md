# Catálogo do plugin aprendizado

Lista de tudo o que mora neste plugin. A skill `aprendizado:guardar-skill` acrescenta uma linha a cada
skill nova, e a `aprendizado:recomendar-skills` usa esta lista para evitar repetição e sugerir limpeza.

## Ferramentas

| Skill | Para que serve |
|---|---|
| `aprender-com-video` | Assistir um vídeo com o plugin `watch` e guardar as lições como skill. |
| `guardar-skill` | Guardar como skill uma lição de um vídeo, de uma conversa ou de uma correção. |
| `recomendar-skills` | Sugerir skills para usar, instalar ou aprender, e limpar as que sobram. |

## Skills aprendidas

| Skill | O que ensina | Origem | Data |
|---|---|---|---|
| `recomendar-skills` (atualizada) | Ferramentas para testar: earshot (som), reanimate (animação), teardown (simulador 3D), Kensaku (busca no PC) e a receita fazer, medir, corrigir | Vídeo "Mais 15 projetos open source do GitHub que valem o seu tempo, Vol. 22" (Eddwan Hallen) | 08/11/2026 |

Skills de um projeto só ficam no `.claude/skills/` do próprio projeto e não entram nesta lista.
