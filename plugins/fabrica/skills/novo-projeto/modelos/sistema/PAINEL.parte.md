- **No computador:** dois cliques em `Abrir {{NOME_ARQUIVO}}.bat` (abre o sistema no navegador; para fechar, feche a
  janela preta). Ou `npm start`. Precisa do Node.js 22 ou mais novo (https://nodejs.org, versão LTS).
- **Os dados** ficam na pasta `dados/` deste computador, com uma cópia por dia em `dados/copias/`. Não vão para o
  GitHub. Para levar para outro computador, copie a pasta `dados/` inteira. No menu do sistema, "Baixar cópia dos
  dados" salva tudo num arquivo.
- **Mudar alguma coisa:** abra uma conversa no Claude Code com este repositório e peça em português.
