# Biblioteca de seções

Pedaços prontos para o site. Cada arquivo tem um comentário dizendo **quando usar**, o HTML da seção e o CSS dela.

Para usar: copie o HTML para o lugar certo do `site/index.html`, copie o que está dentro de `<style>` para o **fim** de
`site/estilo/secoes.css`, troque o texto de exemplo (e apague cada `data-exemplo`) e rode `npm run verificar` e
`npm run telas`. Esta pasta não é publicada.

| Arquivo | Para quê |
|---|---|
| `precos.html` | planos ou pacotes lado a lado, com um em destaque |
| `equipe.html` | quem faz: foto, nome e papel |
| `video.html` | um vídeo em destaque (arquivo próprio ou YouTube) |
| `logos-de-clientes.html` | faixa com logos de quem já contratou (só com autorização) |
| `formulario.html` | formulário de contato (precisa de um serviço que receba os envios) |
| `texto-longo.html` | página de leitura: sobre, artigo, termos |
